# 指标与归因方法

| 指标 | 分子/公式 | 粒度与边界 |
|---|---|---|
| 商品 GMV | delivered item price 总和 | BRL，下单月，不含运费 |
| 平台订单 | delivered order_id 数 | order mart 一行一单 |
| 购买人数 | unique customer_unique_id | 月度内去重，不跨月相加 |
| 购买频次 | 订单数 / 购买人数 | 恒等式因子 |
| AOV | GMV / 平台订单 | 含多 item、多 Seller 的整单金额 |
| 迟到率 | 实际送达日 > 预计日的已送达订单 / 可观测订单 | 同一天不同小时不算迟到，缺失排除 |
| 复购率 | 窗口内订单数 ≥2 的用户 / 窗口内购买用户 | 非未来复购预测，不是注册留存 |
| cohort 留存 | 某 cohort 在第 k 月购买人数 / cohort 首月人数 | 未观察到的未来格不填 0 |
| Seller 次月留存 | 月 t 活跃且 t+1 活跃 Seller / 月 t 活跃 Seller | 最后一个可观测月不算；无单非永久退出 |
| AB 购买率差 | treated target 均值 − control target 均值 | 用户级；依赖实验分配假设 |
| 相对 uplift | 购买率差 / control 购买率 | 不与百分点混淆 |
| Top30 uplift | 预测排序前 30% 内 treated-control 购买率差 | 一致的总体排序；validation 选模，test 评估 |
| 情景 ROI | (增量购买者×假设毛利 − 触达成本) / 触达成本 | 输入是假设，不是测得财务结果 |

## 精确分解

`GMV = Buyers × Frequency × AOV`。三个因子同时变化时有交互项，固定替换顺序会改变贡献。Shapley 枚举 3!=6 种替换顺序，取各因子边际金额变化平均，合计严格等于 GMV 差值。先用一个小例子理解：销量 2→4、单价 3→5，GMV 6→20；销量贡献 `(4−2)×(3+5)/2=8`，价格贡献 `(5−3)×(2+4)/2=6`。

地区/品类/买家类型/Seller 的 `delta_i = GMV_after_i − GMV_before_i`；`贡献百分点_i = delta_i / 总体上期GMV ×100`。增量和下降均保留，以免“只看下降项”夸大损失。每个维度完整加总一次；不同维度高度重叠，不能跨维度相加。一个类别贡献为 −3.5pp，不代表因果导致了 −3.5pp。

## 从描述走向诊断

1. 检查表行数、唯一键、FK、导出覆盖、订单状态与聚合守恒。
2. 看指标树，回答人数/频次/客单哪个变化最大。
3. 地区/品类/用户/Seller 下钻，锁定交叉子群（例如 SP × watches_gifts）。
4. 检查月份长度、相同前 28 天、未取消状态口径；必要时对比去年同期、同星期几、非异常区域。
5. 将根因列为待验证假设：曝光、缺货、活动、竞争、履约。按可能解释规模、取证成本、行动可逆性排序。
6. 索取缺失数据验证；真正评价干预效果需要随机实验或有充分依据的准实验，不用算术贡献冒充因果。

日异常检测使用同星期几历史 8 周中位数与 MAD，至少 6 个历史点；只是探索性提示，零 MAD 时不强行产生极端 z，未作多重检测校正。
